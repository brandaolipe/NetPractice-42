# NetPractice

## Description

**NetPractice** is a networking project from the 42 curriculum. Its goal is
to introduce the fundamentals of TCP/IP networking through a series of 10
practical levels, where the student must fix or configure small networks
(hosts, switches, routers and the Internet) so that every device can 
communicate as expected.

This project focuses on:

- IPv4 addressing and the binary representation of addresses
- Subnet masks and CIDR notation
- Network address, broadcast address and usable host range
- Switches and routers

## Instructions

1. You need to have access to the project files provided by 42.
2. Open the `index.html` file in your browser.
3. Choose between training mode or evaluation mode.
4. For each level (1 to 10), fill in the missing or incorrect fields in the interface.
5. Click **Check again** until every connection is valid.
6. Click **Get my config** and save the resulting `.json` file.
7. Place the 10 configuration files into the repository.
